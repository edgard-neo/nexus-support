# Política de segurança

## Reportando uma vulnerabilidade

Não abra uma issue pública para relatar uma vulnerabilidade. Envie os detalhes
ao mantenedor por um canal privado disponível no perfil do projeto.

Inclua a versão afetada, os passos para reproduzir o problema e, se possível,
uma sugestão de correção.

## Segredos

Nunca inclua chaves de API, tokens, senhas ou dados pessoais em issues,
pull requests, logs ou commits. Use as variáveis de ambiente documentadas no
`.env.example`.
